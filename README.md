a service of MVP Forge LLC. Launching January 1, 2027.

  chassis (`~/workspace/ai-receptionist/ai-receptionist-plan.md` §4.1, demo pack:
  Volunteer Home Services). The live Retell talk-to-it demo is NOT connected yet.

  anything. Checkout (Stripe) opens January 1, 2027.
- Brand: deep navy / white, sky-blue accent #38bdf8. Wordmark: "AvAIlable" with
  the AI in sky blue; pronounced "available."
